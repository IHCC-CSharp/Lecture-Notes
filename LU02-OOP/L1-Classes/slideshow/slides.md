# Classes

## **WHY** Do we needs classes

By: Luke Matheis

---

# Speedrun

- Programs grow → more complexity and change.
- Objects help us manage both.
- Principles + Tools for building with objects = OOP
- Each object handles a slice of the program.
- Objects hide their own complexity.
- We only deal with 1–2 objects at a time.

---

# Managing Complexity

- 200-line programs: easy to track.
    - We can keep all details in our heads.
    - We can understand the whole program at once.
- 20,000-line programs: too many details to remember.
    - As programs grow, we need ways to manage complexity.

---

# Principles vs. Features

- Principles > language features.
- Fun fact: C (Linux kernel) manages complexity without OOP features.
- Use features to support good principles.

---

# Swapping Objects

- Well-designed objects can be swapped for others.
- The rest of the program doesn’t need to know.

---

# Object-Oriented Programming

Build programs from many small objects working together.
