# Methods

Add methods to our classes to off load business logic from the main program to the class.
The class will be responsible for managing its own data and behavior.
This is a key principle of OOP: encapsulation.

# Key Principles of OOP

- Encapsulation: The class is responsible for managing its own data and behavior.
- Abstraction: The class provides a public interface for interacting with its data and behavior, while hiding the implementation details.
- Inheritance: The class can inherit behavior and data from a parent class, allowing for code reuse and a hierarchical structure.
- Polymorphism: The class can have multiple forms, allowing for flexibility and extensibility in the code.
