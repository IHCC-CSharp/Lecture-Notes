# C# Lecture Notes

This repository contains the lecture notes for the C# course.
Each Learning Unit (LU) has its own folder, and within each LU, there is a subfolder for each lecture (L1, L2, etc.).
Each lecture folder contains the relevant code files and a `README.md` file with explanations and instructions.
This `README.md` file are notes for the instructor and are not meant to be a comprehensive guide for students.

## Getting a copy

To get a copy of the lecture notes, you can clone this repository using Git:

```bash
https://github.com/IHCC-CSharp/Lecture-Notes.git
```

This repository will change over time.
To update your local copy with the latest changes, you can pull the latest changes from the repository:

```bash
git pull origin main
```
