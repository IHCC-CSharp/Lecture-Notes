# C# Lecture Notes

This repository contains the lecture notes for the C# course.
Each Learning Unit (LU) has its own folder, and within each LU, there is a subfolder for each lecture (L1, L2, etc.).
Each lecture folder contains the relevant code files and a `README.md` file with explanations and instructions.
This `README.md` file are notes for the instructor and are not meant to be a comprehensive guide for students.

## Table of Contents

| Learning Unit        | Description                                                                                        |
| -------------------- | -------------------------------------------------------------------------------------------------- |
| LU01 The C# Way      | Start with C# fundamentals, including syntax, decision making, loops, and functions.               |
| LU02 OOP             | Learn object-oriented programming (OOP) through classes, objects, abstraction, and static members. |
| LU03 APIs            | Build APIs that return HTML and JSON responses to clients.                                         |
| LU04 Databases       | Work with SQLite using Dapper (a micro-ORM) to perform CRUD operations on real data.               |
| LU05 Inheritance     | Apply inheritance and polymorphism to create more reusable and maintainable code.                  |
| XXXX Midterm         | Finish LU05 with a midterm exam covering LU01-LU05.                                                |
| LU06 Data Structures | Explore enums, database-to-model mapping, and how Entity Framework simplifies data access code.    |
| LU07 Interfaces      | Design more flexible applications by using interfaces effectively.                                 |
| LU08 TDD             | Practice test-driven development (TDD) by writing unit tests before implementation code.           |
| LU09 .NET            | Get an introduction to the broader .NET ecosystem and business app development in C#.              |

## Getting a copy

To get a copy of the lecture notes, you can clone this repository using Git:

```bash
https://github.com/IHCC-CSharp/Lecture-Notes.git
```

This repository will change over time.
To update your local copy with the latest changes, you can pull the latest changes from the repository:

```bash
git pull origin main
```
